# 金句引用卡

大号引号 + 巨型金句 + 作者署名 + 一句注解的引用卡，用于知识视频中引用书中金句、名人观点或自己总结的核心句。调研中「引用增强可信度」是知识类博主的高频需求，原库只有数据来源引用卡（source-citation-card），缺观点/金句引用。

- 引号符号是视觉锚点，200px 橙色衬线字（Georgia），区别于正文无衬线字体。
- 金句字号 88px / 800，字距 0，最多约 2 行（约 30 字），自动换行平衡。
- 作者与注解同行底部排列，前置一段 120px×8px 橙色短横线；注解为 `#9A9A9A`，弱一级，为空时自动隐藏。
- 承载卡 `rgba(20,20,20,.94)`，圆角 6px，无描边无阴影；默认透明叠加，`exportMode=mp4` 时切换为 `#0D0D0D` 深色底。
- 配色：文字 `#F5F5F2`，强调 `#FF5A1F`，来源标签 `#9A9A9A`；避免蓝绿色系。正文字体为 `"PingFang SC", "Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif`。
- 动作：卡片从左擦入（`clipPath`，`expo.out` 0.55s）→ 引号与来源标签淡入 → 金句遮罩上推（`expo.out` 0.7s）→ 短横线生长 → 作者、注解淡入上移；4.5s 卡片向右擦出（`power3.in` 0.38s）。
- 可寻帧：单一确定性 GSAP 时间线，无随机与循环。

## 变量

| 变量 | 说明 |
| --- | --- |
| kicker | 右上角来源类型标签，如「书里的一句话」 |
| quote | 金句正文，建议 15–30 字 |
| author | 出处署名，书名或人名 |
| note | 一句注解，解释这句话为什么重要 |
| accent / foreground | 强调色与文字色 |

## 禁用项

- 不虚构引用出处；author 必须真实可溯源。
- 不在卡内混入数据图表元素。
