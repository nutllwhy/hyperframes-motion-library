# 金句引用卡

大号引号 + 巨型金句 + 作者署名 + 一句注解的引用卡，用于知识视频中引用书中金句、名人观点或自己总结的核心句。调研中「引用增强可信度」是知识类博主的高频需求，原库只有数据来源引用卡（source-citation-card），缺观点/金句引用。

- 引号符号是视觉锚点，衬线字体 Georgia 区别于正文等宽字体。
- 金句字号 74px，最多约 2 行（约 30 字），自动换行平衡。
- 作者与注解同行底部排列，注解颜色弱一级。
- 默认透明叠加；`exportMode=mp4` 时切换为深色底。
- 强调色默认橙色 `#FF5A36`，避免蓝绿色系。
- 可寻帧：单一确定性 GSAP 时间线，无随机与循环。

## 变量

| 变量 | 说明 |
| --- | --- |
| kicker | 右上角来源类型标签，如「书里的一句话」 |
| quote | 金句正文，建议 15–30 字 |
| author | 出处署名，书名或人名 |
| note | 一句注解，解释这句话为什么重要 |
| accent / foreground | 强调色与文字色 |

## 禁用项

- 不虚构引用出处；author 必须真实可溯源。
- 不在卡内混入数据图表元素。
