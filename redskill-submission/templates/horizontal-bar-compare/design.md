# 横向条形对比

横向条形更适合视频快速阅读，用来表达两种方法、两个对象或两个阶段之间的指标差异。画布安全区由两条高对比数据条完整占据，数值与标签直接贴近数据；只根据传入数值控制条长，不增加推测性的坐标轴和排名。

- 无卡片底，左上角一条 168px×8px 橙色短横线引出标题；MP4 导出底色 `#0D0D0D`。
- 数据条为直角实色：轨道 `rgba(245,245,242,.12)`，前一条填充 `#9A9A9A`，后一条填充 `#FF5A1F`；对应名称与数值分别为 `#C8C8C8` / `#F5F5F2` 与 `#C8C8C8` / `#FF5A1F`。
- 字体：`"PingFang SC", "Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif`；数值 `tabular-nums`；字距 0。
- 动作：短横线生长 → 标题遮罩上推（`expo.out`）→ 轨道依次从左生长（`power3.inOut`）→ 填充条与数值同步从 0 增长（`expo.out` 0.9s，间隔 0.18s，直接落定）→ 结论淡入上移；5.02s 整体向右擦出（`power3.in` 0.38s）。
