# 关键词爆破

一个巨型关键词从中心爆发出现，配合冲击环、光晕与收缩副标题，用于视频开头钩子或段落转折。是「上线前模板盘点」中列出的第一优先补齐方向。

- 关键词是唯一视觉主体，字号极大（236px），最多支持约 6–8 个汉字，超长会自动换行并铺满画面。
- 冲击环与光晕只承担爆发感，不承载信息，标记为 `data-layout-ignore`。
- 副标题与注脚解释关键词的立场，注脚可用作使用场景提示。
- 默认透明叠加；`exportMode=mp4` 时切换为深色底。
- 强调色默认橙色 `#FF5A36`，避免蓝绿色系。
- 可寻帧：单一确定性 GSAP 时间线，无随机与循环。

## 变量

| 变量 | 说明 |
| --- | --- |
| kicker | 关键词上方的小提示词，两侧自带短横线 |
| keyword | 巨型关键词主体 |
| subtitle | 关键词下方的一句解释 |
| note | 底部注脚，常用于使用场景说明 |
| accent / foreground | 强调色与文字色 |

## 禁用项

- 不添加英文装饰词、模板编号。
- 不虚构数据；本模板不承载任何数字。
