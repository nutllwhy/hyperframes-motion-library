# 关键词爆破

一个巨型关键词从遮罩中快速上推出现，伴随整体从 1.06 收回原大小的轻微镜头感，用于视频开头钩子或段落转折。是「上线前模板盘点」中列出的第一优先补齐方向。

- 关键词是唯一视觉主体，字号极大（256px / 900），最多支持约 6–8 个汉字，超长会自动换行并铺满画面。
- 关键词下方一条 220px×14px 橙色实色横条承担强调，不承载信息，标记为 `data-layout-ignore`。
- 副标题解释关键词的立场；注脚默认留空，为空时自动隐藏。
- 无卡片底，居中排版；默认透明叠加，`exportMode=mp4` 时切换为 `#0D0D0D` 深色底。
- 配色：关键词 `#F5F5F2`，强调 `#FF5A1F`，提示词与注脚 `#9A9A9A`；避免蓝绿色系。
- 字体：`"PingFang SC", "Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif`；字距 0。
- 动作：0.1s 关键词遮罩上推（`expo.out` 0.42s），整体同步 `scale 1.06→1`；之后 3.9s 内线性缓推到 1.025；提示词淡入 → 横条生长（`power3.inOut`）→ 副标题淡入上移 → 注脚淡入；4.66s 整体淡出（0.26s）。
- 可寻帧：单一确定性 GSAP 时间线，无随机与循环。

## 变量

| 变量 | 说明 |
| --- | --- |
| kicker | 关键词上方的小提示词 |
| keyword | 巨型关键词主体 |
| subtitle | 关键词下方的一句解释 |
| note | 底部注脚，默认为空 |
| accent / foreground | 强调色与文字色 |

## 禁用项

- 不添加英文装饰词、模板编号。
- 不虚构数据；本模板不承载任何数字。
