# 圆环占比

SVG 圆环从 0 扫到目标百分比，中心数字同步滚动，右侧标签与说明解释这个数字的含义。知识类视频表达「占比、概率、比例」时的经典样式，补齐库中环形数据表达的空缺。

- 圆环用 `stroke-dashoffset` 驱动，数值与圆环共用同一缓动（`power3.out` 1.7s），保证同步，直接落定。
- 圆环描边 28px、平头端点：轨道 `rgba(245,245,242,.12)`，填充为 Accent 实色。
- 百分比数值限制在 0–100；超过 100 会被截断到 100。
- 右侧文字区以一段 96px×8px 橙色短横线开头，下接主标签与说明；说明为空时自动隐藏。
- 承载面板 `rgba(20,20,20,.94)`，圆角 6px，无描边无阴影；默认透明叠加，`exportMode=mp4` 时切换为 `#0D0D0D` 深色底。
- 配色：文字 `#F5F5F2`，强调 `#FF5A1F`，说明 `#C8C8C8`；避免蓝绿色系。
- 字体：`"PingFang SC", "Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif`；数字 200px / 800，`tabular-nums`；字距 0。
- 动作：面板从左擦入（`clipPath`，`expo.out`）→ 标题遮罩上推 → 轨道与中心数字淡入 → 0.7s 圆环扫描与数字滚动 → 短横线生长、主标签遮罩上推、说明淡入上移；4.94s 面板向右擦出（`power3.in` 0.4s）。
- 可寻帧：单一确定性 GSAP 时间线，无随机与循环。

## 变量

| 变量 | 说明 |
| --- | --- |
| title | 画面标题，说明这个占比讲什么 |
| value | 百分比数值（0–100），驱动圆环与数字滚动 |
| unit | 单位符号，通常是 % |
| desc | 主标签，说明这个百分比的主体 |
| note | 一句解释，说明剩下部分或对比关系 |
| accent / foreground | 强调色与文字色 |

## 禁用项

- 不虚构口播中没有的百分比；value 必须来自真实数据源。
- 不添加额外指标或英文标签。

## 竖屏版（portrait/）

- 1080×1920，时长 6s（横屏 5.5s +0.5s 纵向阅读补偿），退场擦出在 5.44s。
- 布局从「左圆环右文字」改为纵向堆叠：标题 → 780px 大圆环（数字 230px）→ 文字区（短横线 + 标签 + 说明）。
- note 底部贴近面板边缘，纵向铺开达标。
- 底部 padding 200px 避开平台 UI 遮挡区。
- 变量声明与横屏逐一相同，预设双画幅共享。
- 铺开门槛镜像：横 ≥56%、纵 ≥76%。
