# 动效模板目录

20 个可复用动效模板，覆盖数据可视化、透明叠加和知识讲解。

完整源码：https://github.com/nutllwhy/hyperframes-motion-library

在线演示：https://nutllwhy.github.io/hyperframes-motion-library/

## 数据可视化（9 个）

### 柱状图增长

- ID：`bar-chart-grow`
- 时长：6s
- 画布：1920×1080
- 用途：3–7 根垂直柱形从底部弹性增长，带数值标签与网格线，适合业绩对比、多维度数据分布。
- 标签：柱状图、增长、对比、多系列

### 数字计数器

- ID：`number-counter`
- 时长：5s
- 画布：1920×1080
- 用途：巨型数字从 0 滚动到目标值，可选环形进度条，适合里程碑、KPI、累计数据展示。
- 标签：数字、计数器、滚动、KPI、里程碑

### 折线绘制

- ID：`line-chart-draw`
- 时长：7s
- 画布：1920×1080
- 用途：折线从左侧逐段绘制到右侧，数据点依次弹出，下方填充区域晕染展开，适合时间序列趋势。
- 标签：折线图、趋势、时间序列、绘制动画

### 数据脉冲

- ID：`metric-pulse`
- 时长：6s
- 画布：1920×1080
- 用途：适合增长数据、里程碑、成绩与单项 KPI 的横屏数据动效。
- 标签：数据、增长、里程碑、横屏

### 大数字结论卡

- ID：`big-number-card`
- 时长：5s
- 画布：1920×1080
- 用途：用一个巨型数字和一句解释承接核心结论，适合知识视频里的效率、成本、提升幅度表达。
- 标签：数字、结论、效率、知识视频

### 前后对比数字

- ID：`before-after-stat`
- 时长：5.5s
- 画布：1920×1080
- 用途：把过去与现在、旧方法与新方法的关键数字做成强对比，适合讲工具提效和流程改造。
- 标签：前后对比、效率、数字、方法论

### 横向条形对比

- ID：`horizontal-bar-compare`
- 时长：5.5s
- 画布：1920×1080
- 用途：两组指标横向条形展开，适合传统方法 vs 新方法、两个工具或两个对象的快速比较。
- 标签：条形图、对比、方法、百分比

### Top 排名卡

- ID：`top-rank-list`
- 时长：5.5s
- 画布：1920×1080
- 用途：三条排名逐条弹出，适合工具推荐、影响因素排序、原因权重和 Top 3/Top 5 类内容。
- 标签：排名、Top3、列表、权重

### 拐点趋势线

- ID：`turning-point-line`
- 时长：6s
- 画布：1920×1080
- 用途：趋势线绘制后点亮关键拐点，适合讲增长变化、版本演进、方法生效的关键时刻。
- 标签：趋势、拐点、折线、增长

## 知识讲解（8 个）

### 数据来源引用卡

- ID：`source-citation-card`
- 时长：5s
- 画布：1920×1080
- 用途：下三分之一引用卡展示来源、日期、核心数字和统计口径，适合给知识视频增加可信度。
- 标签：引用、来源、证据、数据

### 概念解释卡

- ID：`concept-spotlight`
- 时长：5s
- 画布：1920×1080
- 用途：透明玻璃卡片聚焦一个概念名、解释句和补充提示，适合知识视频里的术语解释、方法论定义。
- 标签：概念、解释、术语、透明

### 三步流程

- ID：`three-step-flow`
- 时长：6s
- 画布：1920×1080
- 用途：三个步骤卡片与连接线依次生长，适合 SOP、教程步骤、知识框架的口播叠加。
- 标签：步骤、流程、教程、透明

### 误区纠正

- ID：`myth-fact-swap`
- 时长：5.5s
- 画布：1920×1080
- 用途：把“常见误区”划掉并切换到“真实情况”，适合观点纠偏、认知反转、知识澄清。
- 标签：误区、纠正、反转、透明

### 重点标注

- ID：`key-point-marker`
- 时长：4.5s
- 画布：1920×1080
- 用途：下三分之一的重点句标注动效，带角标和扫描下划线，适合金句、结论和操作提醒。
- 标签：重点、标注、金句、透明

### 清单核对

- ID：`checklist-pop`
- 时长：5s
- 画布：1920×1080
- 用途：三条检查项逐条弹出并完成勾选，适合总结步骤、注意事项、行动清单。
- 标签：清单、勾选、总结、透明

### 时间线推进

- ID：`timeline-scan`
- 时长：5.5s
- 画布：1920×1080
- 用途：三个时间节点沿路径依次点亮，适合讲版本变化、阶段推进、历史演变。
- 标签：时间线、阶段、演变、透明

### 因果链路

- ID：`cause-chain`
- 时长：5.5s
- 画布：1920×1080
- 用途：原因、机制、结果三段式链路，适合解释为什么、怎么发生、带来什么结果。
- 标签：因果、机制、解释、透明

## 透明叠加（3 个）

### 双数据对比

- ID：`stat-duel`
- 时长：5s
- 画布：1920×1080
- 用途：两组明确数据的横向对比，可透明叠加在实拍画面底部。
- 标签：对比、百分比、透明、纪录片

### 状态转折

- ID：`status-split`
- 时长：5s
- 画布：1920×1080
- 用途：把常规与异常、过去与现在等两种状态做成章节式对照。
- 标签：对照、章节、透明、转折

### 极值刻度

- ID：`number-impact`
- 时长：5s
- 画布：1920×1080
- 用途：巨型关键词、单项百分比与同值刻度组成的冲击型叠加动效。
- 标签：数字、刻度、百分比、透明
