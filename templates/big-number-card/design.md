# 大数字结论卡

覆盖画面安全区的编辑式结论页承载一个核心数字，用橙色数字制造第一视觉落点。左侧只放结论与数字，右侧只放必要解释，不为其他内容预留空白。无卡片底，靠顶部 8px 橙色短横线、排版与留白建立层次。

- 默认背景透明，但主版面按独立全屏镜头设计；MP4 导出底色 `#0D0D0D`。
- 配色：文字 `#F5F5F2`，强调 `#FF5A1F`，小标签 `#9A9A9A`，说明 `#C8C8C8`，说明上方分隔线 `#3A3A3A`（2px）。
- 字体：`"PingFang SC", "Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif`；数字 360px / 800，`tabular-nums`；字距统一为 0。
- 动作：短横线生长（`power3.inOut`）→ 小标签淡入 → 前缀遮罩上推（`expo.out`）→ 数字从 0 滚动到目标值（`expo.out` 1.2s，直接落定）→ 说明区从左擦入（`clipPath`）；4.5s 整体向右擦出。
- 数字、单位、结论说明均为变量；小标签为空时自动隐藏。
- 不使用网格、英文状态码或无意义斜线装饰。
