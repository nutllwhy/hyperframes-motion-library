# 章节标题

巨型章节编号 + 竖分隔线 + 标题区的横向章节页，用于长知识视频分段。设计目标避免「PPT 页眉感」：编号占据左侧 300px 栏、超大字号（210px），标题区带说明与要点提示，构成完整画面而非条带。

- 左编号、右标题两栏布局，编号下方的进度条示意章节推进。
- 章节编号为字符串变量，可填 `02`、`三`、`PART 2` 等。
- 默认透明叠加；`exportMode=mp4` 时切换为深色底。
- 强调色默认橙色 `#FF5A36`，避免蓝绿色系。
- 可寻帧：单一确定性 GSAP 时间线，无随机与循环。

## 变量

| 变量 | 说明 |
| --- | --- |
| sectionNumber | 章节编号，超大字号显示 |
| title | 章节标题，最多约 12–14 字 |
| subtitle | 副标题，说明本段讲什么 |
| note | 要点提示，左侧橙色竖线强调 |
| accent / foreground | 强调色与文字色 |

## 禁用项

- 不添加口播中没有的英文标签、状态词。
- 章节编号只承担顺序含义，不虚构时间与数据。

## 竖屏版（portrait/）

- 1080×1920，时长 5s（横屏 4.5s +0.5s 纵向阅读补偿）。
- 布局从「左编号右标题」三栏 grid 改为纵向堆叠：编号区（380px 巨型编号 + 进度条）→ 水平分隔线 → 标题区。
- 底部 padding 210px，主动避开平台 UI 遮挡区，核心内容锚定中上 2/3。
- 变量声明与横屏逐一相同（名称、类型、hidden），预设双画幅共享。
- 铺开门槛镜像：横 ≥56%、纵 ≥76%；实测 86%×78%。
