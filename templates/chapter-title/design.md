# 章节标题

巨型章节编号 + 竖分隔线 + 标题区的横向章节页，用于长知识视频分段。设计目标避免「PPT 页眉感」：编号占据左侧 340px 栏、超大字号（320px），标题区带说明与要点提示，构成完整画面而非条带。无卡片底，靠排版与留白建立层次。

- 左编号、右标题两栏布局，编号下方一段 96px 宽、8px 高的橙色短横线示意章节推进。
- 章节编号为字符串变量，可填 `02`、`三`、`PART 2` 等。
- 默认透明叠加；`exportMode=mp4` 时切换为 `#0D0D0D` 深色底。
- 配色：文字 `#F5F5F2`，强调 `#FF5A1F`（编号与短横线），小标签与要点 `#9A9A9A`，副标题 `#C8C8C8`，分隔线 `#3A3A3A`。避免蓝绿色系。
- 字体：`"PingFang SC", "Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif`；编号 `tabular-nums`；标题 128px / 800，字距 0。
- 动作：编号遮罩上推（`yPercent 105→0`，`expo.out` 0.7s）→ 分隔线自上而下生长（`power3.inOut`）→ 短横线生长、「章节」小字淡入 → 标题遮罩上推 → 副标题、要点淡入上移 12px（`power2.out`）；4.0s 整体向左擦出（`clipPath`，`power3.in` 0.4s）。
- 可寻帧：单一确定性 GSAP 时间线，无随机与循环。

## 变量

| 变量 | 说明 |
| --- | --- |
| sectionNumber | 章节编号，超大字号显示 |
| title | 章节标题，最多约 12–14 字 |
| subtitle | 副标题，说明本段讲什么 |
| note | 要点提示，位于标题区底部，上方一条细分隔线；为空时自动隐藏 |
| accent / foreground | 强调色与文字色 |

## 禁用项

- 不添加口播中没有的英文标签、状态词。
- 章节编号只承担顺序含义，不虚构时间与数据。

## 竖屏版（portrait/）

- 1080×1920，时长 5s（横屏 4.5s +0.5s 纵向阅读补偿），退场擦出在 4.5s。
- 布局从「左编号右标题」三栏 grid 改为纵向堆叠：编号区（380px 巨型编号 + 短横线）→ 水平分隔线（从左向右生长）→ 标题区（标题 108px）。
- 底部 padding 210px，主动避开平台 UI 遮挡区，核心内容锚定中上 2/3。
- 变量声明与横屏逐一相同（名称、类型、hidden），预设双画幅共享。
- 铺开门槛镜像：横 ≥56%、纵 ≥76%。
