# Top 排名卡

用于工具推荐、影响因素排序、原因权重排序。三条排名铺满画面安全区并逐条出现，数值右侧对齐，方便视频观众快速扫读。编号只表示真实排名，不附加英文状态或其他序号。

- 无卡片底，左上角一条 168px×8px 橙色短横线引出标题；每条排名下方一条分隔线，第一名为 4px 橙色实线，其余为 `rgba(245,245,242,.16)` 2px。MP4 导出底色 `#0D0D0D`。
- 配色：第一名的编号与数值为 `#FF5A1F`、名称 `#F5F5F2`；其余编号 `#9A9A9A`、名称与数值 `#C8C8C8`。
- 字体：`"PingFang SC", "Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif`；编号与数值 `tabular-nums`；字距 0。
- 动作：短横线生长 → 标题遮罩上推（`expo.out`）→ 0.6s 起每 0.2s 一条：分隔线从左生长（`power3.inOut`）、编号与名称淡入上移、数值从 0 滚动（`expo.out` 0.8s，直接落定）→ 结论淡入；5.02s 整体向右擦出（`power3.in` 0.38s）。
