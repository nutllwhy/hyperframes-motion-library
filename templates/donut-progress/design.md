# 圆环占比

SVG 圆环从 0 扫到目标百分比，中心数字同步滚动，右侧标签与说明解释这个数字的含义。知识类视频表达「占比、概率、比例」时的经典样式，补齐库中环形数据表达的空缺。

- 圆环用 `stroke-dashoffset` 驱动，数值与圆环共用同一缓动，保证同步。
- 百分比数值限制在 0–100；超过 100 会被截断到 100。
- 刻度条（10 格）按数值比例点亮，只装饰、不承载信息。
- 默认透明叠加；`exportMode=mp4` 时切换为深色底。
- 强调色默认橙色 `#FF5A36`，避免蓝绿色系。
- 可寻帧：单一确定性 GSAP 时间线，无随机与循环。

## 变量

| 变量 | 说明 |
| --- | --- |
| title | 画面标题，说明这个占比讲什么 |
| value | 百分比数值（0–100），驱动圆环与数字滚动 |
| unit | 单位符号，通常是 % |
| desc | 主标签，说明这个百分比的主体 |
| note | 一句解释，说明剩下部分或对比关系 |
| accent / foreground | 强调色与文字色 |

## 禁用项

- 不虚构口播中没有的百分比；value 必须来自真实数据源。
- 不添加额外指标或英文标签。

## 竖屏版（portrait/）

- 1080×1920，时长 6s（横屏 5.5s +0.5s 纵向阅读补偿）。
- 布局从「左圆环右文字」改为纵向堆叠：标题 → 780px 大圆环（数字 230px）→ 文字区（标签 + 说明 + 刻度条）。
- 刻度条移到 note 上方，让 note 底部贴近面板边缘，纵向铺开达标。
- 底部 padding 200px 避开平台 UI 遮挡区。
- 变量声明与横屏逐一相同，预设双画幅共享。
- 铺开门槛镜像：横 ≥56%、纵 ≥76%；实测 75%×78%。
